# BAZIS Scripts

Local Git history for the BAZIS assembly exporter. No remote is configured.

Runtime files currently used by BAZIS:
- `C:/Users/WORKSTATION/Documents/BazisMCP/tools/assembly/`
- `//RG/Bazis/Scripts/Export Asamblare.js`

This repository keeps reviewed copies of the assembly source and tests. Generated
PDFs, model files, private configuration and credentials are not versioned.

To undo a change, revert the relevant commit here, then copy the changed files back
to the runtime locations above. Reverting repository files alone does not change
the installed exporter. Preserve unrelated local changes when deploying.
