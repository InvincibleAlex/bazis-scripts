PARAMETRII CARTUSULUI EXPORT COTE

Sablon citit din nou la fiecare export:
Cartus_A4_Portret_cote.json
Poti inlocui acest JSON cu alt sablon schema 2 salvat din editor.
Pozitiile celulelor nu determina continutul: legaturile folosesc numele dintre acolade.

AUTOMAT DIN MODEL / EXPORT
{proiect}     Numele fisierului modelului, fara extensie. Poate fi suprascris manual.
{corp}        Numele modulului/corpului din sectiunea curenta.
{placa}       Numarul placii si desemnarea ei BAZIS.
{material}    Numele materialului placii.
{dimensiuni}  Latime X, inaltime Y si grosime native, in mm.
{bucati}      Numarul exemplarelor cu aceeasi desemnare in proiect.
{data}        Data generarii PDF-ului.
{pagina}      Pagina curenta / total pagini, pentru PDF-ul complet.

MANUAL IN Parametri_cote.json
{client}, {proiectant}, {verificator}
Completeaza valorile dintre ghilimele si salveaza fisierul ca UTF-8.
Poti adauga alte chei proprii si le folosesti in celule ca {cheie}.
Cimpurile automate pentru placa raman goale pe paginile generale ale ansamblului.
Parametrii fara valoare raman goi. Valorile de proba din editor nu sunt date de productie.

Asezarea desenelor si tabelelor se calculeaza exact ca inainte de cartus.
Intreaga pagina rezultata este incadrata uniform in zona chenarului; continutul
landscape se roteste ca bloc 90 grade antiorar, fara rearanjarea tabelelor sau a desenelor. Cartusul ramane drept.
Pagina PDF fizica urmeaza dimensiunile din JSON (in acest sablon: A4 portret).
