EXPORT TABELE - Cubis / Komodo / Holver

In BAZIS rulati scriptul Export Cubis.js aflat langa acest folder.
Terminalul de progres se deschide automat inainte de citirea modelului.
Arata citirea placilor, accesul la baza si rezultatul fiecarui tabel Excel.
La final ramane deschis; poate fi inchis dupa mesajul TERMINAT.
Node, Python si componentele pentru Excel sunt in acest folder comun.
Nu sunt necesare Codex, o instalare locala Python/Node sau MCP activ.

Sabloanele raman in \\RG\Bazis\Sabloane Tabel. Acolo se modifica datele
de contact si cataloagele PAL / ABS.

Accesul la baza foloseste implicit utilizatorul si parola din runtime.json.
Nu este necesara configurarea autentificarii pe fiecare calculator.
Configurarea locala criptata este folosita numai daca parola comuna este eliminata.
Citirea materialelor foloseste tranzactii Firebird read-only.

Fisierele de lucru pentru Excel se creeaza separat in TEMP pe PC-ul
care exporta. Mai multe calculatoare pot exporta simultan.
Documentele rezultate se salveaza in folderul de export ales de script.

runtime.json contine cai relative, adresa bazei si autentificarea comuna.
Nu mutati sau stergeti separat subfolderele runtime, node_modules si tools.
